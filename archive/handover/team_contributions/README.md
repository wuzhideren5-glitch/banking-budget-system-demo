# Historical Team Contribution Patches

本归档目录保存同事提交包中的原始 PDD patch，属于历史合并材料，不是当前 schema、导航或运行口径的事实来源。

阅读规则：

- 当前事实以 `CONTEXT.md`、`docs/development/current-system-map.md`、当前 `apps/web` / `apps/api` 代码和运行库为准。
- 本目录内提到的旧 `report_account`、旧 `driver_*`、旧预测工作台、旧导航隐藏策略等，只有在正式 PDD 或当前代码中仍存在时才可采用。
- 如需从历史 patch 复用需求，必须先按当前数据库和前后端 Module 重新校验。
