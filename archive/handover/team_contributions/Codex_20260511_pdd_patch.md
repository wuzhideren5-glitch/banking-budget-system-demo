## System PDD 建议新增 (§0.9)

- 优化**费用数据同步管理**模块的入口方式：由依赖部署机本地固定文件，调整为由前端页面直接上传 Excel 后再进入后端解析流程，降低联调与上线环境对桌面目录结构的依赖。
- 费用整体框架同步支持上传 `.xls`、`.xlsx`、`.xlsm` 三类文件格式，上传后由后端统一完成预算部门、产品部门与预算科目框架的解析与入库。
- 费用执行实际同步同步改为页面上传触发，用户在数据同步管理页选择文件后即可完成校验、预览和写库，避免因未找到服务器本地源文件导致同步失败。
- 数据同步管理页补充文件选择、同步前校验与按钮禁用态，未选择文件时不允许直接预览或同步，降低误操作风险。
- 费用框架上下文加载条件放宽，在仅存在预算部门框架数据的情况下也允许进入同步识别流程，提升不完整初始化场景下的可用性。

> 插入位置：System PDD 的 `## 0.8` 之后，新增 `## 0.9` 小节。

## 补充说明

1. **接口行为变化**：费用整体框架同步与费用执行实际同步接口改为接收上传文件，接收方联调时需使用前端上传入口，不再依赖部署机桌面固定路径。
2. **兼容格式**：同步链路兼容 `.xls`、`.xlsx`、`.xlsm`，接收方只需保证 Python 依赖已按 `apps/api/requirements.txt` 安装完成。
3. **数据库迁移**：本次不涉及数据库结构迁移，无需执行额外建表或字段变更脚本。
4. **交付约束**：按团队交付规范，发布包不包含 `.env`、`var/data/*.db`、`node_modules/`、`dist/` 等敏感或可再生内容，接收方需自行准备环境变量与数据库文件。
