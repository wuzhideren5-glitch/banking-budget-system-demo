# 测试服务器部署说明

## 端口与访问

- 前端 Vite 服务：`0.0.0.0:8443`
- 后端 FastAPI 服务：`0.0.0.0:8009`
- 本机访问：`http://127.0.0.1:8443`
- 域名访问：`http://guanheng.webank.com`
- API 文档：`http://127.0.0.1:8009/docs`

## CORS / Host 放行

- 前端 `vite.config.ts` 已配置 `host: "0.0.0.0"`、`port: 8443`、`allowedHosts: ["guanheng.webank.com"]`。
- 后端 `backend/.env` 已配置 `CORS_ORIGINS`，放行 `127.0.0.1:8443`、`localhost:8443`、`guanheng.webank.com`。
- 后端 `CORS_ORIGIN_REGEX` 放行 `10.65.*.*:8443` 和 `guanheng.webank.com`。

## 启停

```bash
bash start.sh
bash stop.sh
```

`start.sh` 会：

- 使用 `backend/pyproject.toml` 和 `backend/.python-version` 创建/复用 uv 隔离虚拟环境。
- 启动后端 `uvicorn app.main:app --host 0.0.0.0 --port 8009`。
- 使用 `pnpm` 或 `npm` 启动前端 Vite `--host 0.0.0.0 --port 8443`。
- 将 PID 写入 `.pids/`，日志写入 `.logs/`。

## 打包注意

- 目前仅完成部署配置合并，暂不打包。
- 后续打包时应包含 `start.sh`、`stop.sh`、`backend/pyproject.toml`、`backend/.python-version`、`backend/.env`、`data/`、`download_template/` 和业务 Excel。
- 后续打包时不应包含 `.pids/`、`.logs/`、`node_modules/`、`.venv/`、`backend/.venv/`、`.git/`。
