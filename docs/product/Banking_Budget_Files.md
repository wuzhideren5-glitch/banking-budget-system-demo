## 费用预算执行报表

- `apps/api/app/services/expense_budget_execution_modes.py`：费用预算执行报表 mode 合同 Module，统一承载 display/export 报表模式白名单和报表视角白名单；resolver 和 export service 只引用这一份合同，避免查询、部门、科目、平铺导出口径分散漂移。
- `apps/api/app/services/expense_budget_execution_report_resolver.py`：费用预算执行报表响应 resolver，统一编排查询、月报、部门模式、科目模式的数据源读取、筛选上下文、标题和说明文案；共用 report selection interface、report resolution plan interface、报表视角校验、报表月 1-12 校验、subject id 正整数校验、非法输入业务错误映射和 planned report payload resolver。
- `apps/api/app/services/expense_budget_execution_export.py`：费用预算执行报表导出服务，统一承载导出模式白名单、导出工作簿类型白名单、导出金额单位白名单、导出视角白名单、导出模式到 workbook 类型/文件名的 export plan、plan-driven workbook builder、Excel workbook 构造、空数据占位行、金额单位缩放、百分比格式和公共 workbook 响应适配。
- `apps/api/app/routers/expense_budget_execution.py`：费用预算执行报表 HTTP Interface；路由只负责 HTTP 参数到 report selection adapter、export selection adapter、export options adapter、服务调用、report error adapter 和错误映射。
- `apps/api/test_expense_budget_execution_report_resolver.py`：费用预算执行报表 resolver 服务级测试，覆盖 shared mode/perspective 合同引用、report resolution plan 用途/模式/视角白名单校验、报表月 1-12 guard、subject id 正整数 guard、非数字输入到业务错误的映射、planned report payload resolver 未知模式拒绝、运行时上下文、筛选上下文、响应 envelope、note、body fields、查询/月报/部门模式/科目模式 payload 和模板实际口径上下文。
- `apps/api/test_expense_budget_execution_export.py`：费用预算执行导出服务级测试，覆盖导出模式白名单、导出工作簿类型白名单、导出金额单位白名单、导出模式到 workbook 类型/文件名的 export plan、plan-driven workbook builder、部门模式和平铺模式 workbook、空数据占位行、金额单位小数保留、百分比格式、下载文件名和通用 workbook 响应合同。
- `apps/api/test_expense_budget_execution_router.py`：费用预算执行报表路由级测试，覆盖 HTTP 参数到报表 selection、export selection 与 export options 的统一映射，以及 report error 到 HTTP 400 的统一映射，守卫路由不重新分散报表模式、导出参数装配和错误映射。
- `apps/web/src/lib/expenseBudgetExecutionApi.ts` 与 `apps/web/src/lib/expenseBudgetExecutionViewModel.ts`：费用预算执行报表前端请求 Module，展示请求只携带报表 selection，导出请求使用独立 export mode 和 payload builder 承载 `query/template/subject/flat` 导出合同；金额单位和月度展开字段只用于前端格式化和导出请求，且金额单位 divisor 与月度展开字段由 view-model/request builder 承载，页面不传入树形区块知识或读取金额单位 option 结构；报表 mode 的合法值、金额单位合法值、subject id 正整数合同、树报表、树区块、关键字归属 UI facts 和展示/导出报表月份归一化由 view-model 集中承载，避免 display selection、export options、storage hydration 与页面展示规则混用。
- `apps/web/e2e/expense-budget-execution-view-model.spec.ts`：费用预算执行前端 view-model 测试，覆盖展示请求不携带导出专用金额单位且会归一化报表月份、导出请求保留金额单位和月份/展开字段且不要求页面传入树形区块知识、flat 导出 mode payload 序列化、报表 mode UI facts 不散落在页面组件、报表月份 1-12 合同归一化、storage report mode/amount unit 合法值归一化、金额单位 divisor lookup，以及 subject id 正整数归一化和非法 subject id 不进入请求。
