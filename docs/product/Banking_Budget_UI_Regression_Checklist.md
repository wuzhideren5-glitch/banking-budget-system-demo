# UI 回归验收清单

| 项目 | 说明 |
|------|------|
| 适用范围 | 全局 UI 体系、FinancialGrid / ReportGrid、现有与新增前端模块 |
| 固定入口 | `http://127.0.0.1:8443/` |
| 固定视口 | 1024px、1366px |

---

## 1. 全局壳层

- [ ] 只启动一个前端入口：`http://127.0.0.1:8443/`。
- [ ] 顶栏、左导航、多标签、右侧助手、底栏都使用统一金融办公系统风格。
- [ ] 左右折叠按钮可用，resize handle 不遮挡内容。
- [ ] 标签页过多时更多菜单可用，关闭按钮不误触。
- [ ] 页面不存在大屏驾驶舱、宣传型首页、满屏 KPI 卡片墙。

## 2. 标准页面

- [ ] 页面打开后直接进入工作区，不先显示大段功能介绍。
- [ ] 标题、工具栏、主体工作区、状态反馈位置稳定。
- [ ] 主按钮最多一个，普通操作为次按钮，危险操作有明显危险态。
- [ ] 输入框、下拉框、弹窗、浮层圆角和阴影统一。
- [ ] 加载、空态、错误、成功、警告都有一致样式。

## 3. ReportGrid / FinancialGrid

- [ ] 表头固定在表格容器顶部。
- [ ] 关键识别列固定在左侧。
- [ ] 数字右对齐并使用 tabular 数字。
- [ ] 行层级通过缩进、字重、浅底色表达。
- [ ] 普通网格线很淡，分组/冻结/汇总结构线更清楚。
- [ ] 行展开/收起可用。
- [ ] 列组展开/收起可用，收起后仍保留上下文。
- [ ] 汇总行、明细行、只读行、锁定行、错误行视觉可区分。
- [ ] 1024px 下不出现整页横向滚动；横向滚动只发生在表格内部。

## 4. EditableFinancialGrid

- [ ] 可编辑单元格、只读单元格、公式锁定单元格、错误单元格状态明确。
- [ ] 键盘录入不会改变列宽或导致布局跳动。
- [ ] 空值语义正确：只读缺失显示 `-`，可编辑缺失显示为空输入态。
- [ ] 错误提示靠近单元格或行，不只在页面顶部显示。
- [ ] 保存、刷新、导入、导出不会破坏现有业务写入保护。

## 5. 报表与导出

- [ ] 筛选栏包含业务必需的年份、版本、产品/部门、单位等口径。
- [ ] 单位切换后页面展示和导出文件一致。
- [ ] 导出按钮按当前筛选条件导出。
- [ ] 树形报表导出后仍能看出汇总/明细结构。
- [ ] 预算展示报表、费用预算执行报表、透视表都遵守同一报表语言。

## 6. AI / Agent / 智能报告 / PPT

- [ ] AI 建议使用克制提示样式，不像最终业务结果。
- [ ] 低置信度、未匹配、质量问题进入待确认或质量报告。
- [ ] AI 区块不展示 SQL 原文、原始 JSON、模型提示词。
- [ ] Agent 推荐透视视角与普通聊天文本视觉区分。
- [ ] 生成报告/PPT 后能看到质量反馈和缺失项。

## 7. 构建检查

- [ ] `npm run build` 通过。
- [ ] 构建仅允许已知 chunk size warning，不允许 TypeScript/Vite 错误。
- [ ] 8443 可访问并返回 200。
- [ ] 不额外启动 5173、5178 或其他前端入口。
