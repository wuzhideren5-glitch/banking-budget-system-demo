# Simulation Specification (Budget Tool)

本文档用于沉淀当前“模拟测算（正算/倒算）”的指标取数、参数输入、结果校验和跑批刷新规则。它不是数据科目自动补齐脚本说明，也不得被用来恢复旧指标编码或旧驱动表。

适用项目：银行业务预算管理系统当前仓库  
数据库：`var/data/common.db`、`var/data/budget_2026.db`  
金额单位：**亿元**

## 1. 目标与总原则

### 1.1 目标
- 校验模拟测算所需的数据科目运行记录、机构及产品指标节点和绑定是否已经存在
- 缺失项输出待维护清单，由“机构及产品指标”按当前模型补建并同步为数据科目运行主键
- 明确预算/实际公式（`budget_formula` / `actual_formula`）和 `need_calc` 的业务口径
- 通过预算输入、导入或跑批链路维护 `budget_data` 全年月度数据
- 保证每个业务口径“一个业务实体 = 一套唯一闭环科目”

### 1.2 唯一闭环原则（必须）
- **资产业务（贷款 / 同业投资）**
  - 外部：`利息收入 + 资产收益率`
  - FTP：`FTP利息支出 + FTP利率`
- **负债业务（存款）**
  - 外部：`利息支出 + 负债付息率`
  - FTP：`FTP利息收入 + FTP利率`

> 不允许同一业务出现多个并存的“同名同义利率科目”。

---

## 2. 数据模型约束（项目内）

- `data_account`：科目主表，主键为唯一指标号码 `data_acct_code`，含 `budget_formula`, `actual_formula`, `allow_manual_entry`, `value_type`
- `data_account_metric_binding`：唯一指标号码与产品前缀指标主键的绑定表，`scope_code` 由唯一指标号码产品前缀派生
- `budget_data`：按 `data_acct_code + product_code + period_id + version_id + budget_actual` 存值

关键唯一键：
- `data_account_metric_binding`: `metric_node_code` 是产品前缀指标主键；`data_acct_code = metric_node_code`，`scope_code` 必须等于 `metric_node_code` 的产品前缀
- `budget_data`: `(data_acct_code, product_code, period_id, version_id, budget_actual)` 唯一

## 3. 公式规则（统一口径）

## 3.1 贷款（含开鑫贷/企企贷/车车贷等资产类贷款）

- 预算（利息收入）  
  `贷款利息收入 = 贷款日均 * 贷款年化收益率 / 1.06 / 12`

- 实际（收益率）  
  `贷款年化收益率 = 贷款利息收入 / 贷款日均 * 1.06 * 12`

---

## 3.2 同业资产投资（标准指标树资产口径）

- 预算（利息收入）  
  `同业利息收入 = 同业资产日均 * 同业资产年化收益率 / 12`

- 实际（收益率）  
  `同业资产年化收益率 = 同业利息收入 / 同业资产日均 * 12`

> 同业资产不考虑增值税折算。

---

## 3.3 存款业务（负债外部口径）

- 预算（利息支出）  
  `存款利息支出 = 存款日均 * 存款年化付息率 / 12`

- 实际（付息率）  
  `存款年化付息率 = 存款利息支出 / 存款日均 * 12`

---

## 3.4 资产 FTP（贷款/同业）

- 规则：FTP 年化利率比对应外部资产收益率低 `0.1% ~ 0.2%`（随机）
- 预算（FTP 利息支出）  
  `资产FTP利息支出 = 资产日均 * 资产FTP年化利率 / 12`
- 实际（FTP利率）  
  `资产FTP年化利率 = 资产FTP利息支出 / 资产日均 * 12`

---

## 3.5 负债 FTP（存款）

- 规则：FTP 年化利率比对应外部负债付息率高 `0.1% ~ 0.2%`（随机）
- 预算（FTP 利息收入）  
  `负债FTP利息收入 = 负债日均 * 负债FTP年化利率 / 12`
- 实际（FTP利率）  
  `负债FTP年化利率 = 负债FTP利息收入 / 负债日均 * 12`

---

## 4. 标准指标树映射规则

本节列出的短码是产品内 `local_metric_code` 或功能归族匹配提示，不是可直接写入的 `data_acct_code`。运行时必须从 `data_account_metric_node`、`data_account_metric_binding` 和 `data_account` 解析当前产品前缀唯一指标号码；不得把短码拼接为旧 `*.CORP` 或 `metric_code.scope` 形态。

### 4.1 外部口径
- 营业收入 -> `03.09.05.01.039`
- 利息净收入 -> `03.02.01.01.001`
- 利息收入 -> `03.01.01.01.025`
- 利息支出 -> `04.01.06.01.012`
- 手续费净收入 -> `03.04.01.01.003`
- 手续费收入 -> `03.04.01.01.001`
- 手续费支出 -> `04.03.01.01.004`

### 4.2 FTP口径
- 模拟测算只接受当前 `metric_node_code` / `data_acct_code` 体系，不再使用 `X03`、`X10`、`X11` 旧编码。
- 贷款规模 -> `01.01.01.01.017`
- 资产减值损失 -> `06.01.01.01.001`
- 贷款风险成本 -> `06.01.01.02.007`
- 税金及附加 -> `07.01.01.01.001`
- 所得税费用 -> `07.02.01.01.001`

## 5. 模拟数据参数（本项目当前约定）

## 5.1 总盘子
- 资产规模：`1000`
- 负债规模：`900`
- 贷款规模：约 `资产 * 60%`
- 同业资产规模：约 `资产 * 25%`
- 存款规模：约 `负债 * 80%`

## 5.2 利率范围
- 贷款收益率：`7% ~ 10%`
- 同业资产收益率：`1% ~ 2%`
- 存款付息率：`1% ~ 2%`
- 资产FTP利率：对应外部收益率 `-0.1% ~ -0.2%`
- 负债FTP利率：对应外部付息率 `+0.1% ~ +0.2%`

## 5.3 月度波动
- 总盘子与产品分配可加小幅随机扰动（例如 ±2% / ±4%）
- 年化率预算与实际可有小幅偏离，但必须保持业务逻辑方向

## 5.4 特殊小规模产品
- `其他小小产品存款`、`小企业保证金存款`日均按小规模模拟，目标约 `10`
- 两者应单独建模，不应并入其他存款产品聚合重复计入

## 6. 缺口处理规则（给 AI 的执行要求）

1. 识别产品与科目缺口  
   - 对每个目标业务判断是否已有当前产品前缀唯一指标号码
   - 缺失时输出缺口清单，不得按旧最大编码顺延或自动新增主数据

2. 建立映射  
   - 缺失的 `data_account_metric_binding` 只能通过“机构及产品指标”保存链路正式创建
   - 模拟测算运行路径不得在后台自动创建数据科目、指标节点或绑定

3. 填公式  
   - 公式调整必须进入“机构及产品指标”的正式写入链路
   - 设置 `need_calc = 1` 后通过预算事实刷新跑批重算

4. 写模拟数据  
   - `budget_actual=0` 写预算，`budget_actual=1` 写实际
   - 使用预算输入、正式导入或 BudgetDataWriter 写入 `budget_data`

5. 清理历史重复残留  
   - 清理“同名同义但无公式引用”的旧利率科目（尤其历史 FTP 重复）前必须先输出影响清单
   - 删除必须先在“机构及产品指标”确认指标体系调整，再同步清理运行表绑定与 `budget_data`

6. 执行跑批  
   - 通过“预算事实刷新跑批”统一完成公式落库、预算汇总刷新、对比同步与聚合表生成

---

## 7. 质量验收清单（建议每次执行后跑）

### 7.1 唯一性检查
- 每个业务实体只保留一条外部利率、一条FTP利率
- 不存在同名重复利率科目

### 7.2 公式一致性检查
- 每条利息科目公式引用正确对应的日均与利率
- 每条利率科目公式能反推对应利息科目

### 7.3 范围检查
- 贷款/同业/存款利率落在约定范围
- FTP利率与对应外部利率差值满足 +/- 0.1%~0.2% 方向要求

### 7.4 规模检查
- 贷款总日均约 600
- 同业总日均约 250
- 存款总日均约 720
- 小规模存款科目日均约 10

## 8. 执行入口

旧模拟脚本已退休。主数据缺口应通过“机构及产品指标”处理；模拟测算接口只读取当前机构及产品指标树、机构产品指标运行引用与年度预算事实，不负责自动补主数据。

跑批刷新：

```bash
curl -X POST "http://127.0.0.1:8009/api/budget-actual-batch/run" \
  -H "Content-Type: application/json" \
  -d '{"product_code":"ALL","version_id":3,"budget_actuals":[0,1],"run_formula":true,"rebuild_summary":true,"sync_compare":true,"rebuild_aggregate":true}'
```
