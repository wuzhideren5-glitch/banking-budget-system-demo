## 1. 两大类（最常用）

| 大类 | **推荐中文名** | 需求代号 / 英文 | 是什么 |
|------|----------------|-----------------|--------|
| **基础表** | **单机构指标表**（简称 **指标表**） | `entity_metric_table` | 一个主体 + 一张表类型；**行 = 指标，列 = 时间**；公式按「月」计算，各月只是**数值**不同 |
| **输出表** | **矩阵报表** | `matrix_report` | **不维护科目**；只定义版式（行×列从哪取数）；在 **预测输出 · 模式 B** 运行 |

**记忆口诀**

- **指标表**：先定义科目和公式，再按月录入、按月计算。  
- **矩阵表**：不新增科目，只把多个主体/版本/指标排成一张对比表导出。

与矩阵总册 §0 对应关系：**A = 指标表**，**B / C / D = 矩阵报表**（三种版式）。

## 2. 单机构指标表：三层（别和时间维度混）

时间不单独建一套公式；**时间是数值维度**，**公式逻辑各月相同**（跨表可取「某月」的数，但规则本身不按时间拆表维护）。

| 层次 | **推荐名称** | 菜单入口 | 说明 |
|------|--------------|----------|------|
| 定义层 | **指标表定义** | 预算数据维护 → **机构及产品指标** | 某主体下的「业务状况表 / 损益表…」：指标树、科目性质、**月内公式** |
| 事实层 | **指标表录入** | 预算数据输入 → **数据录入** | 某年、某滚动月、某版本下的 1–M 实际、(M+1)–12 预测等 |
| 结果层 | **指标表输出**（**模式 A**） | 预算数据输入 → **预测输出** | 跑批后的 1–12 月 + **全年列**（全年由 **时间汇总规则** 生成，不是另一套公式文案） |

### 2.1 汇总型 / 引用型单机构指标表（如 AA 损益表）

**外观**与单机构指标表相同：一个主体（如 **AA 微众银行**）、**行 = 指标科目树**、**列 = 时间**（25 年实际、26 年预算、26 年预测等）。  
**差别**在于：很多行的 **26 年预测（及预算）并非在 AA 上手工录入**，而是由 **月内公式** 从下属产品/机构的 **单机构指标表** 汇总或引用而来。

| 判断 | 说明 |
|------|------|
| **仍属单机构指标表** | 在 **机构及产品指标** 下维护 AA 的科目树（AA01、AA0101…）与 **月内公式** |
| **不是矩阵报表** | 矩阵是「多主体并排、常只取少数指标」；AA 表是「一个主体的一张完整纵表」 |
| **矩阵可从它取数** | 例如矩阵②「税前利润分解」从各主体 **指标表输出** 取 `税前利润`；AA 损益表跑批结果也可作为矩阵的数据源 |

```text
三级产品 B01、A01…  指标表录入 + 输出
         ↓ 月内公式（SUM / 跨表引用 A01/表/指标）
AA 损益表（汇总型单机构指标表）  指标表定义在「机构及产品指标」
         ↓ 指标表输出（模式 A）→ 25实际 / 26预算 / 26预测 各列
矩阵② 等  从 AA 或其它主体的「某一指标」取数展示（模式 B）
```

**典型主体**：**AA** 全行损益、**A/B/C… 机构群** 汇总表（若也做成「行=指标、列=时间」的一张表）。

### 2.2 AAA 微众集团：保留机构树，不设指标表

| 维度 | 约定 |
|------|------|
| **机构及产品树** | **保留 AAA** 作为集团根（导航、归属、统计「几个一级主体」） |
| **机构及产品指标 / 数据录入** | **不维护** AAA 的单机构指标表（左侧可选中 AAA，仅提示无表） |
| **集团合并视图** | 由三级产品数据经规则汇总，在 **预测输出 · 矩阵报表**（如集团合并损益）展示 |

**AA 微众银行 · 指标表清单**（仅以下 6 张，不含矩阵专用表）：

1. 业务状况表  
2. 损益表  
3. 资产负债表（余额）  
4. 资产负债表（日均）  
5. 资产质量表  
6. 利息净收入表  

**不在 AA 指标维护范围内的表**（走矩阵模板）：产品利润表、风险驱动表、净利息驱动表等。

**发需求时建议写法**：

- 「维护 **AA / 损益表** 的 **汇总型单机构指标表**（指标表定义 + 从产品表汇总的月内公式）」  
- 避免写成：「把 AA 损益做成矩阵表」或「在矩阵里维护 AA01 科目树」

**与矩阵②（税前利润分机构）的区别**：

| 维度 | AA 损益类（汇总型指标表） | 矩阵② 税前利润分解 |
|------|---------------------------|-------------------|
| 维护入口 | **机构及产品指标** | **预测规则 · 矩阵模板** |
| 行 | 完整损益科目树 | 主要是各 **机构/产品** |
| 列 | **时间**（实际/预算/预测） | **版本**（常单指标） |
| 主体数 | **1 个**（AA） | **多个** |

## 3. 公式与汇总：两个词

| 名称 | 维护入口 | 作用 |
|------|----------|------|
| **月内公式** | 机构及产品指标 · 公式配置 | 表内计算；跨表 `主体/表名/指标代码` 取数；年化类由引擎按「当前月 / 全年列」切换上下文 |
| **时间汇总规则** | 预测规则 · 时间汇总（阶段 1） | 12 个月 → **全年**（SUM、期末、加权日均等）；**不写进**月内公式 |

**矩阵报表**中不维护公式，只有单元格 **取数引用**（`source_ref`）指向某主体指标表跑批结果。

## 4. 矩阵报表：三种版式（提需求用编号）

| 编号 | 中文名 | `layout_mode` | 行 × 列 |
|------|--------|---------------|---------|
| **矩阵①** | 风险驱动表 | `version_x_metrics` | 机构 ×（版本 × 多指标） |
| **矩阵②** | 税前利润分解表 | `single_metric` | 机构 × 版本（整表一个指标） |
| **矩阵③** | 指标×机构×时间 | `metrics_x_entity_time` | 指标 ×（机构 × 时间） |

详见 [`OrgProduct_Matrix_Output_PDD.md`](OrgProduct_Matrix_Output_PDD.md)。

## 5. 与菜单对照

```text
预算数据维护
  ├── 机构及产品                 → 机构树
  └── 机构及产品指标             → 指标表定义 + 月内公式

预算数据输入
  ├── 数据录入                   → 指标表录入
  ├── 预测规则（阶段 1 起）       → 时间汇总规则、矩阵报表模板
  └── 预测输出
        模式 A                   → 指标表输出
        模式 B                   → 矩阵报表
```

## 6. 发需求「一句话模板」

| 场景 | 示例表述 |
|------|----------|
| 补科目 | 维护 **B01 / 企业金融业务状况表** 的 **指标表定义** |
| 配公式 | 为 **B01** 配置 **月内公式**（跨表引用 **AA/损益表/01.01**） |
| 试点链路 | **指标表录入** + **指标表输出** 试点 **B01**，2026 年 3 月滚动 |
| 矩阵需求 | 新增 **矩阵② 税前利润分解** 模板（**不是**改指标表科目） |
| AA 损益汇总 | 维护 **AA / 损益表** 为 **汇总型单机构指标表**，26 预测由产品表 **月内公式** 汇总 |
| 避免混淆 | 「国际业务整体」用 **矩阵模板** 合并 D+AB，**不在**机构树加 AC 实体 |

## 7. 实施顺序（与 Rolling PDD 一致）

```text
阶段 0  机构树 ✅ → 指标表定义 → 指标表录入 → 指标表输出（模式 A）
阶段 1  预测规则 · 时间汇总 + 月内公式补全
阶段 2  预测规则 · 矩阵模板 + 预测输出（模式 B）
```

## 8. 机构及产品指标 · Excel 导入（默认严格）

| 规则 | 说明 |
|------|------|
| **工作表名** | `机构/产品代码 + 指标表名`，**严格匹配**（如 `AA资产质量表`）；仅少量写死别名（如 `AA净利息收入表`→利息净收入表） |
| **表体四列** | `科目层级`、`科目性质`、`科目代码`、`科目名称`；按**列名**与 Excel 对齐，**列顺序不限**；表头简称（如「层级」「代码」）可映射到标准名 |
| **严格模式（默认）** | `strict_import=true`：① 四列表头须齐全（支持合并单元格、多行表头；表头损坏时可四列数据形态推断列号）；② **科目性质** 按列读取、**不限枚举**；③ 仅导入**同时有科目代码+名称**的行（分段标题/空行/仅名称的合计行自动跳过）；④ 层级空时可由代码推断；⑤ 任一行有代码但层级仍无法识别 → 整表不导入 |
| **宽松模式** | `strict_import=false`：允许缺层级/性质时推断或默认、坏行跳过（仅调试或历史坏文件） |
| **导入范围** | 仅更新 Excel 中出现的 sheet；未出现的指标表不改 |

## 9. 易混对照

| 容易混的说法 | 应使用的名称 |
|--------------|--------------|
| 「给风险驱动表加指标」 | 矩阵①是**输出版式**；科目在 **指标表定义**（多在 AA 损益表） |
| 「矩阵里配公式」 | 矩阵只有 **取数引用**；公式在 **月内公式** |
| 「全年公式」 | 全年列用 **时间汇总规则**；月内公式用日历函数区分月/年上下文 |
| 「AC 机构录入」 | AC 国际业务（整体）**不进树**；用 **矩阵模板** 合并 D+AB |
| 「AA 表从各产品取数，算矩阵吧」 | 仍是 **汇总型单机构指标表** + **月内公式**；矩阵只负责「多主体对比展示」 |
| 「截图那种 AA01 科目表」 | **指标表定义**（机构及产品指标），不是矩阵模板 |
