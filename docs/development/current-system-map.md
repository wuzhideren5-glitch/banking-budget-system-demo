## Current Business Invariants

- **机构及产品指标** 是预算指标、公式和录入口径的唯一配置入口；`data_account` / `data_account_metric_node` / `data_account_metric_binding` 只作为机构及产品指标的运行引用表，不再作为独立前端配置页面或投影维护入口。
- **唯一指标号码** 是产品前缀 `metric_node_code`，例如 `A01.01.01.001`；`data_account.data_acct_code` 必须等于 `data_account_metric_binding.metric_node_code`。
- `data_account` 物理表必须已经是当前 11 列合同；历史 `legacy_product_code`、`legacy_dimension` 或缺少 `budget_rule_code` / `formula_calc_mode` / `allow_manual_entry` 等当前字段的旧表不再启动时自动补列或重建。
- `product_type` 不再是物理表或运行视图。发现旧 `product_type` table/view 时，bootstrap 会直接删除旧对象，产品节点维护必须从“机构及产品”进入，运行产品清单由服务从 `org_product_tree_snapshot` 展开。
- `data_account_metric_node` / `data_account_metric_binding` 物理表必须已经是当前指标树与绑定合同；旧本地指标树缺少 `product_code` / `local_metric_code` / `logic_code` / `horizontal_rollup` / `vertical_rollup` / `functional_group_code`，或仍保留退休字段 `metric_rollup_method`，或绑定表仍使用 `data_acct_code = metric_node_code || '.' || scope_code` 约束时，启动直接失败，不再补列、回填或重建。
- `product_code` 是事实查询和展示维度；`scope_code` 由唯一指标号码的产品前缀派生，仅用于绑定校验和运行库一致性检查，不再定义新业务身份。
- 产品层级必须进入唯一指标号码或事实查询维度；指标树派生只读取 `horizontal_rollup`、`vertical_rollup` 和 `logic_code`，不再读取旧 `metric_rollup_method`。
- 启动修复不再把旧 `metric_node_code + scope_code` 或旧后缀式 `data_acct_code` 自动迁移成当前主键；发现旧指标编码时直接失败，避免旧口径继续作为兼容输入。
- `apps/api/scripts/` 不再保留旧产品预算工作台补齐/去重、旧绑定范围合并、旧目录重建、旧本地指标码五级迁移或旧指标树三四级语义重整脚本；当前运行库必须直接维护产品前缀唯一指标号码，旧指标树和旧工作台配置只能清理/按当前模型重导，不能通过活跃脚本继续改写。
