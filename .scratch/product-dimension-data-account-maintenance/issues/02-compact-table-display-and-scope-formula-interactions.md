# 右侧表精简展示与公式范围交互

Type: AFK

## Parent

## What to build

在已打通的 **产品维度数据科目视图** 上，把右侧数据科目表收口成真正可用的产品维护界面。默认只展示业务核心列，技术字段收进详情或更多字段；适用范围列采用简洁摘要；公式列采用状态化展示。

范围摘要要符合当前 PRD 决策：`全行` 直接显示为 `全行`；当前选中叶子产品显示为 `本产品`；当前选中父级产品线显示为 `本产品线`；多产品范围显示为数量摘要；单个其他产品显示其名称。hover 时展示完整产品范围明细。

公式列默认只显示紧凑状态，hover 预览完整公式，点击进入现有公式编辑器。共享 `全行` 科目在产品视图中仍然可见，并且共享影响要有清楚提示，避免用户误以为自己只改了当前产品。

## Acceptance criteria

- [ ] 右侧表默认只展示业务核心列，不默认暴露完整层级编码、指标口径编码、指标族等技术字段。
- [ ] 技术字段有可发现的详情或更多字段入口。
- [ ] 适用范围按 PRD 约定显示为 `全行`、`本产品`、`本产品线`、数量摘要或具体产品名。
- [ ] hover 适用范围摘要时可查看完整产品范围明细。
- [ ] 公式列默认显示紧凑状态，而不是长公式文本。
- [ ] hover 公式状态时可预览完整公式。
- [ ] 点击公式状态可进入现有公式编辑器。
- [ ] `全行` 共享科目在产品视图中保持可见，并有清楚的共享影响提示或等价提示机制。
- [ ] 覆盖范围摘要显示、hover 明细、公式 hover 预览、点击编辑和共享科目提示的测试或可重复验收。

## Agent Brief

**Category:** enhancement  
**Summary:** Turn the product-scoped table into a compact, business-friendly maintenance surface.

**Current behavior:**  
The product-scoped view can be read, but the right-side table still needs to become concise and readable for budget users rather than exposing mostly technical fields.

- Product-scoped table rendering contract  
- Scope-summary formatter and hover-detail contract  
- Existing formula editor entry flow  
- Shared-scope warning or indicator behavior

- [ ] Scope summaries match the PRD display rules.
- [ ] Hover reveals full product scope detail.
- [ ] Formula cells use status display with hover preview.
- [ ] Clicking a formula status opens the existing editor flow.
- [ ] Shared all-product rows remain visible and clearly shared.

**Out of scope:**  
- Adding new rows inline  
- Replacing the formula editor itself
