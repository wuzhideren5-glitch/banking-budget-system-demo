## What to build

把现有 **数据科目维护表** 改造成可 demo 的 **产品维度数据科目视图** 基础版本。用户进入页面后，先选择一个 **系统产品科目**，支持末级产品和父级产品线；页面主结构切换为左侧精简指标树和右侧数据科目表骨架。

当用户选择某个产品后，系统按当前产品上下文返回可用的数据科目行。读取结果必须继续基于现有 **数据科目维护表** 主数据，而不是引入第二套数据模型。叶子产品视图要包含 `全行` 公共科目和适用于当前产品的科目；父级产品线视图要包含 `全行` 公共科目、父级产品线范围科目，以及适用于任一子产品的科目。

这个 slice 的目标是打通“先选产品，再看当前产品数据科目”的完整路径，让页面已经具备稳定的产品上下文和可渲染读取结果。不要在本 slice 中完成公式 hover 预览、范围摘要精修或行内新增。

## Acceptance criteria

- [ ] 页面以产品选择为第一入口，支持末级产品和父级产品线选择。
- [ ] 页面主结构为左侧精简指标树和右侧数据科目表骨架。
- [ ] 未选中产品时，右侧展示清晰空态或占位态。
- [ ] 选中末级产品后，读取结果包含 `全行` 公共科目和适用于该产品的数据科目。
- [ ] 选中父级产品线后，读取结果包含 `全行` 公共科目、父级产品线范围科目和适用于任一子产品的数据科目。
- [ ] 读取结果继续复用现有 **数据科目维护表** 主数据，不新增平行数据科目表。
- [ ] 返回结果已包含右侧表所需的核心业务字段和当前树节点渲染所需信息。
- [ ] 覆盖叶子产品筛选、父级产品线筛选、`全行` 公共科目包含规则和指标树渲染骨架的测试或可重复验收。

## Agent Brief

**Category:** enhancement  
**Summary:** Build the product-first data-account maintenance skeleton and product-scoped read model.

**Current behavior:**  
The current data-account maintenance page behaves like a global master table. Users see a large flat maintenance surface and must infer which rows matter to a given product.

**Desired behavior:**  
The page should begin from product context. Users select a system product or product line first, then see a left indicator tree and a right-side data-account table scoped to that context. The read model must continue using the existing data-account master data and include all-product rows where applicable.

**Key interfaces:**  
- Product selection state and product tree contract  
- Product-scoped data-account read model  
- Indicator-tree navigation model  
- Existing data-account master-data API contracts

**Acceptance criteria:**  
- [ ] Product selection is the first interaction in the page flow.
- [ ] The page layout becomes left indicator tree plus right data-account table skeleton.
- [ ] Leaf-product selection includes all-product rows and matching product-scoped rows.
- [ ] Parent-product selection includes all-product rows, parent-line rows, and descendant-product rows.
- [ ] The read model still comes from the existing data-account master data.
- [ ] The slice is independently demoable as a product-first maintenance view.

**Out of scope:**  
- Formula hover preview and click-through editing polish  
- Scope-summary display rules  
- Inline row creation
