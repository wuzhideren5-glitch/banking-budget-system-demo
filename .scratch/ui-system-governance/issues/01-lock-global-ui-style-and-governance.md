# 锁定全局 UI 风格与治理规范

## What to build

Confirm and codify the global UI direction for the banking budget system as the long-term authority for current and future frontend work. The system should be treated as a modern financial enterprise office tool: warm, concise, premium, low-pressure, and work-area-first. It must not drift toward dashboard, big-screen, BI showpiece, or marketing-page visual language.

This slice should finalize the governance language so every future feature PRD and implementation issue can reference the same standard before defining UI behavior.

## Acceptance criteria

- [ ] The PRD explicitly states that future frontend features must follow the global UI governance and frontend design spec.
- [ ] The global style is documented as modern financial enterprise office UI with Excel-grade table capability.
- [ ] The design direction explicitly rejects global dashboard/big-screen/showcase layouts.
- [ ] The style principles cover warm neutral surfaces, weak grid lines, strong structure lines, small radii, weak shadows, and work-area-first pages.
- [ ] The governance docs are clear enough for AFK agents to use without asking for visual taste decisions.

## Blocked by

None - can start immediately
