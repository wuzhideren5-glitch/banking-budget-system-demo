## 5. 仍存在的差异类型

### ① 业务支出评估表 — 系统输出为 0，标准有数（约 69–72% 一致）

如 `A01.91`、`B01.91` 等：标准 Excel 公式链有值，系统预测输出为 0。  
**原因**: 支出评估表可能未配置完整公式/录入，或 run 引擎未覆盖该表计算链。

### ② AA / A01 部分资产余额类科目（A01.10、A01.11 等）

标准值约为系统输出的 **55–60%**。  
**原因**: 标准含公式中引用了与系统指标树不同的汇总口径或额外调整项。

### ③ 标准中「费率列填金额」的科目（如 A05.19.13.01）

- m1–m3：系统按 **0.2（费率）** 计算 → 手续费支出正常  
- m4–m12：标准单元格为 **2.49亿（绝对金额）**，系统按录入原值或 `余额×录入值` → m4 略差（约 2.51亿 vs 2.49亿）

### ④ 父级汇总行

标准文件中父级行多为 **Excel 行内公式**（=H4+H5）；系统输出由 **指标树公式引擎** 计算。  
对比脚本只对「标准侧求值后有数」的格子计数，父级若公式未求出则跳过。
