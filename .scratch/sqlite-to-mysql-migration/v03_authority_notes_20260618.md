| 类型 | 代码特征 | 原因 |

| 老费用树 | 第二段为 **`.05`**（如 `AA.05`、`A01.05`） | 已退休，由 `.90`/`.91` 体系替代；`init_db` 启动 purge |

### 重名 / 跨表镜像规则（2026-06-18 落地）

| 规则 | 说明 |
|------|------|
| **主表优先** | ``metric_table_name`` 以 `METRIC_TABLE_CANONICAL_PRIORITY` 为准（余额表 > 日均表 > 利息净收入表 …） |
| **镜像行删除** | ``AA利息净收入表`` 中的 ``AA.25.05`` / ``AA.27.05`` 为日均表镜像，已从 v03 删除 |
| **隐式分组** | ``AA.24`` / ``AA.25`` / ``AA.14.02`` 等 GROUP 行写入 v03 + MySQL，父级见 ``IMPLICIT_GROUP_PARENTS`` |

代码：`app/services/v03_metric_node_catalog.py`
