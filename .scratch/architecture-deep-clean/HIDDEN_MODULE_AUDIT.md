# Hidden Module Audit

Date: 2026-05-22

Update 2026-05-31: current navigation and work-area mounting now live in `apps/web/src/app/workspaceCatalog.tsx`; the former `data-product-import` mismatch was resolved by removing that navigation leaf and keeping fee actual import on `input-expense-actual-import`.

## Scope

This audit looks for modules that are not visible from the current left navigation, are only reachable through hidden/debug paths, or still expose backend/database surface without active frontend usage.

Checks performed:

- Compared `NavigationTree.tsx` leaf ids with `WorkArea.tsx` tab cases.
- Scanned frontend `*Content.tsx` exports and imports.
- Compared backend route declarations with frontend `/api/*` call sites.
- Checked current SQLite row counts for likely orphan tables.

## Navigation / WorkArea result

Current navigation has 29 leaf pages and `WorkArea.tsx` has 29 matching tab cases.

There are no remaining normal tab cases that are invisible from navigation. The previously removed `forecast-workbench` and `assumption-basic` pattern is not currently repeated in `WorkArea.tsx`.
