## System PDD 建议新增 (§0.7)

- 本轮将产品科目从单层维护升级为多层结构维护，前端与后端统一支持 `parent_code + level` 的树形表达，产品导入模板与维护页均可维护父子层级。
- 数据科目与产品科目的绑定方式由“单产品”扩展为“多产品 / 全部产品 / 公司级空置”三类范围表达，数据科目维护页新增分层多选交互，并保留后续范围迁移与校验能力。
- Excel 导入交互完成一轮改造：通用导入弹窗支持“新增/更新”与“覆盖”两种模式，预算基础数据导入结果文件明确区分新增、覆盖与失败单元格，提升批量维护可控性与回溯性。
- 本轮同步修复了导入反馈与前端选择交互的若干问题，重点改善产品范围回显、导入结果提示与用户操作闭环。

> 插入位置：System PDD 的 `## 0.6` 之后，新增 `## 0.7 本轮需求变更（2026-05-06）` 小节。

## Database PDD 建议新增 (§0.2)

- `DataAccount` 新增/启用 `product_codes` 范围表达字段，用于承载数据科目与产品科目的多对多范围关系。
- `product_codes` 的业务语义建议统一描述为：
  - `NULL`：适用所有产品；
  - 空字符串：公司级/未分配到具体产品；
  - 逗号分隔代码串：适用指定多个产品。
- `ProductType` 的使用口径需从“单层产品清单”更新为“支持 `parent_code` 与 `level` 的多层产品树”，并明确产品维护、导入模板、前端选择器均按同一层级规则执行。
- 本轮未新增独立业务表，但对既有字段语义与兼容迁移逻辑进行了增强，主合并时需同步更新字段说明与导入约束说明。

> 插入位置：Database PDD 的“本轮同步说明”之后，新增一节说明本轮字段语义与产品层级调整。
