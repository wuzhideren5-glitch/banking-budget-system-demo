## 1. 目标与总原则

### 1.1 目标
- 自动补齐缺失的数据科目（`data_account`）
- 自动补齐报告映射（`report_data_mapping`）
- 填充预算/实际公式（`budget_formula` / `actual_formula`）
- 在 `budget_data` 填充全年（月度）模拟数据
- 保证每个业务口径“一个业务实体 = 一套唯一闭环科目”

### 1.2 唯一闭环原则（必须）
- **资产业务（贷款 / 同业投资）**
  - 外部：`利息收入 + 资产收益率`
  - FTP：`FTP利息支出 + FTP利率`
- **负债业务（存款）**
  - 外部：`利息支出 + 负债付息率`
  - FTP：`FTP利息收入 + FTP利率`

> 不允许同一业务出现多个并存的“同名同义利率科目”。

---

## 2. 数据模型约束（项目内）

- `data_account`：科目主表（含 `budget_formula`, `actual_formula`, `product_code`, `value_type`）
- `report_data_mapping`：报告科目与数据科目映射
- `budget_data`：按 `data_acct_code + period_id + version_id + budget_actual` 存值

关键唯一键：
- `report_data_mapping`: `(report_acct_code, data_acct_code)` 唯一
- `budget_data`: `(data_acct_code, period_id, version_id, budget_actual)` 唯一

---

## 3. 公式规则（统一口径）

## 3.1 贷款（含开鑫贷/企企贷/车车贷等资产类贷款）

- 预算（利息收入）  
  `贷款利息收入 = 贷款日均 * 贷款年化收益率 / 1.06 / 12`

- 实际（收益率）  
  `贷款年化收益率 = 贷款利息收入 / 贷款日均 * 1.06 * 12`

---

## 3.2 同业资产投资（X010102 下资产）

- 预算（利息收入）  
  `同业利息收入 = 同业资产日均 * 同业资产年化收益率 / 12`

- 实际（收益率）  
  `同业资产年化收益率 = 同业利息收入 / 同业资产日均 * 12`

> 同业资产不考虑增值税折算。

---

## 3.3 存款业务（负债外部口径）

- 预算（利息支出）  
  `存款利息支出 = 存款日均 * 存款年化付息率 / 12`

- 实际（付息率）  
  `存款年化付息率 = 存款利息支出 / 存款日均 * 12`

---

## 3.4 资产 FTP（贷款/同业）

- 规则：FTP 年化利率比对应外部资产收益率低 `0.1% ~ 0.2%`（随机）
- 预算（FTP 利息支出）  
  `资产FTP利息支出 = 资产日均 * 资产FTP年化利率 / 12`
- 实际（FTP利率）  
  `资产FTP年化利率 = 资产FTP利息支出 / 资产日均 * 12`

---

## 3.5 负债 FTP（存款）

- 规则：FTP 年化利率比对应外部负债付息率高 `0.1% ~ 0.2%`（随机）
- 预算（FTP 利息收入）  
  `负债FTP利息收入 = 负债日均 * 负债FTP年化利率 / 12`
- 实际（FTP利率）  
  `负债FTP年化利率 = 负债FTP利息收入 / 负债日均 * 12`

---

## 4. 报告科目映射规则（X03 / X10 / X11）

### 4.1 外部口径
- 同业资产外部利息收入 -> `X0301010101`
- 同业资产收益率 -> `X1002`
- 贷款外部利息收入 -> `X0301010103`
- 贷款资产收益率 -> `X1003 / X1004`（按个人/企业）
- 存款外部利息支出 -> `X0301010108`
- 存款付息率 -> `X1103 / X1104`（按个人/企业）

### 4.2 FTP口径
- 同业资产业务内部FTP利息支出 -> `X0301010102`
- 信贷业务内部FTP利息支出 -> `X0301010104`
- 存款业务内部FTP利息收入 -> `X0301010107`
- 负债FTP利率 -> `X1103 / X1104`（按个人/企业）

## 5. 模拟数据参数（本项目当前约定）

## 5.1 总盘子
- 资产规模：`1000`
- 负债规模：`900`
- 贷款规模：约 `资产 * 60%`
- 同业资产规模：约 `资产 * 25%`
- 存款规模：约 `负债 * 80%`

## 5.2 利率范围
- 贷款收益率：`7% ~ 10%`
- 同业资产收益率：`1% ~ 2%`
- 存款付息率：`1% ~ 2%`
- 资产FTP利率：对应外部收益率 `-0.1% ~ -0.2%`
- 负债FTP利率：对应外部付息率 `+0.1% ~ +0.2%`

## 5.3 月度波动
- 总盘子与产品分配可加小幅随机扰动（例如 ±2% / ±4%）
- 年化率预算与实际可有小幅偏离，但必须保持业务逻辑方向

## 5.4 特殊小规模产品
- `其他小小产品存款`、`小企业保证金存款`日均按小规模模拟，目标约 `10`
- 两者应单独建模，不应并入其他存款产品聚合重复计入

## 6. 自动补齐规则（给 AI 的执行要求）

1. 识别产品与科目缺口  
   - 对每个目标业务判断是否已有 A/C/K/L 对应科目  
   - 缺失时新增科目（编码按现有最大编码顺延）

2. 建立映射  
   - 缺失的 `report_data_mapping` 使用 `INSERT OR IGNORE` 补齐

3. 填公式  
   - 覆盖目标科目的 `budget_formula` / `actual_formula`
   - `need_calc = 1`

4. 写模拟数据  
   - `budget_actual=0` 写预算，`budget_actual=1` 写实际
   - 使用 upsert 写入 `budget_data`

5. 清理历史重复残留  
   - 清理“同名同义但无公式引用”的旧利率科目（尤其历史FTP重复）
   - 同步清理其 `report_data_mapping` 与 `budget_data`

6. 重建汇总  
   - 调用 `POST /api/budget-summary/rebuild`

---

## 7. 质量验收清单（建议每次执行后跑）

### 7.1 唯一性检查
- 每个业务实体只保留一条外部利率、一条FTP利率
- 不存在同名重复利率科目

### 7.2 公式一致性检查
- 每条利息科目公式引用正确对应的日均与利率
- 每条利率科目公式能反推对应利息科目

### 7.3 范围检查
- 贷款/同业/存款利率落在约定范围
- FTP利率与对应外部利率差值满足 +/- 0.1%~0.2% 方向要求

### 7.4 规模检查
- 贷款总日均约 600
- 同业总日均约 250
- 存款总日均约 720
- 小规模存款科目日均约 10
